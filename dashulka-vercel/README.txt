Деплой на Vercel (обычный HTML)

1. Распакуйте архив.
2. Загрузите папку dashulka-vercel в GitHub как отдельный репозиторий (index.html должен лежать прямо в корне репозитория).
3. На Vercel выберите Add New -> Project и импортируйте этот репозиторий.
4. В Build and Deployment выберите Framework Preset: Other.
5. Build Command оставьте пустым.
6. Output Directory оставьте пустым (не указывайте dist/build).
7. Deploy. Главная страница будет index.html.

Весь сайт находится в одном HTML-файле, внешние картинки/библиотеки не требуются.
